# 홈(`/`) 랜딩 강화 — 디자이너 → 퍼블리셔 전달서

**목적**: 학습 허브 본문은 유지하고, **홈만** “제품 홍보용 랜딩” 수준의 첫인상·설득력을 더한다.  
**현재 구현**: `src/pages/HomePage.jsx` + `HomePage.css` — 히어로 카드 + eyebrow + 제목 + 리드 문단만 존재.

---

## 1. 기획·개발 쪽 배경 (디자이너 참고)

- 앱 성격: **React 학습 허브** (상단 메뉴로 주제 이동, `실무·심화`는 탭 하위).
- 톤 분리: **홈 = 설득·진입**, **함수·실무 페이지 = 차분한 학습 UI** (허브 스타일은 `hubDemoShell.css` 등과 맞추되, 홈은 더 과감해도 됨).
- 기술 스택: React + Vite, 스타일은 **컴포넌트 단위 CSS** (`HomePage.css`). 디자인 토큰은 전역 `src/index.css`의 `:root` 변수와 정렬.

---

## 2. 디자이너에게 요청할 산출물

### 2.1 필수

| 산출물 | 설명 |
|--------|------|
| **Figma (또는 팀 도구) 프레임** | Desktop ≥1280px, Tablet ~768px, Mobile 360px **3안 중 1안 확정** |
| **컴포넌트 스펙** | 색·타이포·간격·라운드·그림자 (가능하면 `px` + `rem` 병기) |
| **히어로** | 제목 계층, 서브카피, **Primary CTA 1 + Secondary CTA 1** |
| **이득 3칼럼** | 카드 또는 리스트 — 아이콘 유무, 최대 줄 수(2줄 이내 권장) |
| **비주얼 블록** | 정적 이미지 **또는** 짧은 루프(≤8s) 명세 — 안전 영역, 비율(16:9 등) |

### 2.2 권장

- **Empty / 로딩 없음**: 홈은 정적 콘텐츠 위주라 스켈레톤 불필요.
- **다크 모드**: `prefers-color-scheme: dark` 대응 여부를 **디자인에서 명시** (현재 히어로는 일부 다크 보정 있음).
- **모션**: 배경·그라데이션 미세 모션 시, **`prefers-reduced-motion: reduce`일 때 정지** 안내를 노트에 적기.

### 2.3 접근성 (디자이너 체크리스트)

- CTA: **최소 터치 영역 44×44px** (모바일).
- 색 대비: 본문·버튼 텍스트 **WCAG AA** 이상 목표.
- 포커스 링: 버튼·링크에 키보드 포커스 시 **보이는 링** (코드에서는 `--ui-focus-ring` 활용 가능).

## 3. 정보 구조(와이어 수준) — 디자인 시안에 넣을 블록

아래 순서를 **권장 IA**로 잡고 카피는 기획과 합의 후 확정.

1. **히어로**  
   - Eyebrow (한 줄 카테고리)  
   - H1  
   - 리드 (2~3문장 이내)  
   - CTA: 예) Primary「실무·심화 둘러보기」→ `/practice/overview`, Secondary「함수(map)」→ `/functions/map` 등 **실제 라우트와 매핑 표**를 Figma에 적기.

2. **대표 비주얼**  
   - 스크린샷·일러스트·짧은 영상 중 하나. 자산 이름 규칙 예: `home-hero-visual.webp`.

3. **이득 3개**  
   - 예: 복붙 가능한 예제 / 주제별 정리 / 실무·모션·폼 샘플 (카피는 기획 확정).

4. **(선택) 푸터 CTA 또는 한 줄 신뢰**  
   - 강의 연계·내부용 등 **사실만** 기재.

## 4. 구현 시 참고할 토큰·파일 (퍼블리셔용)

| 항목 | 위치 |
|------|------|
| 색·간격·폰트 변수 | `src/index.css` — `:root` (`--accent`, `--text-h`, `--page-content-max`, `--ui-radius-*`, `--space-*` 등) |
| 홈 마크업 | `src/pages/HomePage.jsx` |
| 홈 스타일 | `src/pages/HomePage.css` |

## 5. 디자이너 → 퍼블리셔 인수인계 체크리스트

디자이너가 아래를 넘기면 퍼블리셔가 바로 착수 가능하다.

- [ ] Desktop / Tablet / Mobile **최종 프레임** 링크 + **확정 1안** 표시  
- [ ] **CTA 라벨 + 이동 URL** 표 (Primary / Secondary)  
- [ ] **이미지·영상** export (WebP/AVIF 우선, 2x @3x 필요 시 명시) + `alt` 문구  
- [ ] 타이포: 폰트 웨이트, 크기, 행간, **clamp** 사용 시 min/max 값  
- [ ] 간격: 섹션 간 `margin`/`padding` (또는 8px 그리드 기준 값)  
- [ ] 다크 모드: **별도 프레임** 또는 “라이트만” 명시  
- [ ] 모션: 있음/없음, 있으면 **duration·easing·reduced-motion 대응** 노트  
- [ ] **스펙 아웃된 상태** (hover만 다른 색 등) 정리

## 6. 퍼블리셔 작업 범위·완료 기준

**범위**

- `HomePage.jsx`에 섹션 구조 반영, `react-router-dom`의 `<Link to="...">`로 CTA 연결.
- `HomePage.css`에 디자인 스펙 반영 (가능하면 **토큰 변수** 사용, 하드코딩 색 최소화).
- 이미지는 `public/` 또는 `src/assets/` — 빌드 경로만 팀 규칙에 맞출 것.

**완료 기준 (QA)**

- [ ] 360 / 768 / 1280에서 레이아웃 깨짐 없음  
- [ ] 키보드로 CTA·링크 순서 탐색 가능, 포커스 가시  
- [ ] `prefers-reduced-motion: reduce`에서 과한 애니메이션 없음  
- [ ] Lighthouse 성능: 히어로 **대용량 미디어**가 LCP를 망치지 않도록 (lazy·poster·용량 제한)
